# Буржуй — лендинг веб-студии (Тула)

Сайт: https://murzzsite.github.io/burgui-web/
Заявки: Cloudflare Worker lead-relay, ref V6RJAQJBTL, бот @formsfeedback_bot.

Стек: чистый HTML/CSS/JS, GSAP 3.12.5 + ScrollTrigger, Lenis 1.0.42 (CDN), шрифт Onest.

Живой элемент: экспресс-проверка сайта (8 вопросов), результат уходит в заявку.
Картинки работ взяты с prburgui.ru (портфолио клиента).

Заглушки / уточнить:
- реквизиты оператора в privacy.html;
- список проверок в аудите (написан типовым, сверить с клиентом);
- формулировки «аудит бесплатный, результаты остаются у вас».
